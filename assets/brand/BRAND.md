# AgentIQ Brand Guide

**AgentIQ** is the MCP (Model Context Protocol) product brand that connects AI
agents to **MoltAd** (the agent-directed advertising exchange). AgentIQ has
its **own distinct visual identity** — a mascot-led, dark/copper look —
separate from both the MoltAd site brand (blue, broadcast-mark) and the old
AiIQ identity (green, circuit-brain "A" mark, now retired).

Do not use the MoltAd site OG/logo for AgentIQ listings, and do not use these
AgentIQ assets as the MoltAd site's OG image — see `moltad-assets/BRAND.md`
for the MoltAd site brand.

## Positioning

MCP layer for agent-directed advertising. AI agents (not humans) are the
audience: they discover, recommend, and transact ad placements on behalf of
users. The mascot is an owl — watchful, decisive, "intelligence" — standing
in for the agent making the call.

### Tagline options

1. "Advertise to the agent" (primary — used on `og.png`)
2. "MCP for agent-directed advertising" (used on `twitter.png`)
3. "MCP for MoltAd" (short lockup tag, used under the wordmark on `logo.png`/`avatar` contexts)

## Mascot

A flat-vector geometric **owl** — chosen for "IQ"/watchfulness/decision-making.
Big round eyes each contain a tiny circuit/chip-node pattern (agent
intelligence), compact rounded body, small ear-tufts, no other props or
scenery. Deliberately **not** a lobster/crab (that mark belongs to a
different, unrelated product) and not a generic purple-gradient "AI" orb.

## Colors

| Token | Hex | Usage |
|---|---|---|
| `--agentiq-bg` | `#151109` | Primary dark background ("espresso"/charcoal) |
| `--agentiq-bg-2` | `#1C1610` | Secondary depth shade (avatar backdrop circle, OG panel) |
| `--agentiq-copper` | `#E2793D` | Primary accent — mascot body, taglines, accent bars |
| `--agentiq-cream` | `#F5EDE3` | Primary text/wordmark on dark backgrounds |
| `--agentiq-ink` | `#17130D` | Wordmark on light/transparent backgrounds |

Two-tone mascot (copper + near-black) on a dark charcoal field, in the vein of
"dark espresso header + copper line-art mark" branding — bolder and friendlier
than a pure line-art mark, but still sparse/professional rather than
cutesy-mascot overload.

## Typography

Bold system sans (Arial/Helvetica Black weight) for the wordmark and taglines
— rendered programmatically (not baked into the AI-generated art) so spelling
and kerning are always exact. No custom font license required.

## Asset inventory — avatar vs. logo vs. og (kept separate, do not conflate)

| File | Size | Purpose |
|---|---|---|
| `avatar.png` | 1024×1024 | **Strict square** mascot-only mark for MCP registries / profile pictures. Dark card background, mascot centered, readable at small sizes. |
| `avatar-512.png` | 512×512 | Same composition, smaller. |
| `icon.png` / `icon-512.png` | 1024 / 512 | App icon — matches `avatar.png` composition (safe to reuse for favicons, package icons). |
| `icon-transparent-256.png` | 256×256 | Mascot only, transparent background, no card — for compositing into other UI. |
| `logo.png` | ~1170×460 | **Horizontal lockup**: mascot + "AgentIQ" wordmark + "MCP for MoltAd" tag, transparent background, dark ink text — for light backgrounds (READMEs, docs). |
| `logo-dark.png` | ~1170×460 | Same horizontal lockup, on a solid dark card — for dark UI/README dark-mode. |
| `logo-white.png` | ~1170×460 | Flat white silhouette lockup, transparent background — for compositing onto any dark/colored surface. |
| `og.png` | 1200×630 | **Separate** Open Graph composition — wordmark + "MCP for MoltAd" + tagline "Advertise to the agent" + subtitle, mascot on the right. Not a stretched avatar. |
| `twitter.png` / `twitter.jpg` | 1200×630 | **Separate** Twitter/X card — distinct layout (mascot on the left) and tagline ("MCP for agent-directed advertising"). |

**Rule of thumb:** `avatar.png`/`icon.png` = mascot only, strict square, no
wordmark. `logo.png` = mascot + wordmark, horizontal, for embedding in docs.
`og.png`/`twitter.png` = full marketing composition with tagline, sized for
social link previews — never generated by simply stretching the avatar.

## Generation notes

The mascot (`raw/agentiq-mascot-transparent.png`) was generated once with the
OpenAI Images API (`gpt-image-1`, transparent-background mode) from a prompt
encoding the two-tone copper/charcoal owl brief (see `generate.mjs`). All
other files (`avatar*`, `icon*`, `logo*`, `og.png`, `twitter.*`) are
programmatically composited from that single mascot using `sharp` —
backgrounds, accent shapes, and all wordmark/tagline text are rendered via SVG
locally (not AI-generated) so text is always spelled/kerned correctly and the
layouts are fully reproducible. Run `node generate.mjs` then
`node postprocess.mjs` (from a folder with `sharp` in `node_modules`, e.g.
`ai-marketplace/`) to regenerate.
