# AgentIQ brand assets

AgentIQ's own mark — a dark/copper owl mascot — used for this MCP
package/repo. This is the **AgentIQ** brand, distinct from the MoltAd site
brand (blue) and the retired AiIQ circuit-brain "A" mark (green). Do not
substitute the MoltAd site OG image for these, or vice versa.

Full brand guide (colors, taglines, mascot rationale): see [`BRAND.md`](BRAND.md).

**Which asset for which surface:** MCP registries / profile pictures →
`avatar.png` (strict square, mascot only). README/docs headers →
`logo.png` (or `logo-dark.png` for dark-mode docs). Social link previews
(Open Graph, Twitter/X cards) → `og.png` / `twitter.png` — never the avatar
stretched to a wide aspect ratio.

| File | Size | Use |
| --- | --- | --- |
| `avatar.png` / `avatar-512.png` | 1024 / 512, square | Mascot-only mark for MCP registry profile pictures. Strict square, readable small. |
| `icon.png` / `icon-512.png` | 1024 / 512, square | App/favicon-style icon — same composition as avatar. |
| `icon-transparent-256.png` | 256, square | Mascot only, transparent background, no card. |
| `logo.png` | ~1170×460 | Horizontal lockup: mascot + "AgentIQ" wordmark, transparent bg, dark text — for light backgrounds/READMEs. |
| `logo-dark.png` | ~1170×460 | Same lockup on a solid dark card — for dark UI. |
| `logo-white.png` | ~1170×460 | Flat white silhouette lockup, transparent bg — for compositing onto any surface. |
| `og.png` | 1200×630 | Open Graph / link-preview image — separate composition with tagline, not a stretched avatar. |
| `twitter.png` / `twitter.jpg` | 1200×630 | Twitter/X card — distinct layout from `og.png`. |
